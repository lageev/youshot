# YouShot

YouShot 是一款原生 macOS 菜单栏截图工具，支持当前屏幕、全部屏幕、窗口吸附和自由区域截图，并可在截图原位置直接完成标注。

截图使用 ScreenCaptureKit，以显示器原生像素输出无损 PNG；窗口截图支持透明背景、圆角和阴影配置。

## 功能

- 当前屏幕、全部屏幕、自由区域截图
- 区域框选完成后可直接选择普通截图、手动滚动长截图或自动滚动长截图
- 滚动长截图：自动滚动、Vision 位移配准、实时拼接预览，页面到底后自动停止
- 长截图支持暂停/继续、提前完成、Esc 取消、最大高度保护和完成后首尾裁剪
- 自动规避粘性顶栏、底部浮层和滚动条对拼接匹配的干扰
- 零延迟区域截图会在触发瞬间冻结屏幕，可捕捉失焦后消失的菜单、Popover、Spotlight / Raycast 浮层
- 窗口悬停吸附与单击选取，按住 `⌥` 可临时关闭吸附
- 区域截图完成后，在原位置直接进入标注层
- 矩形、椭圆、直线、箭头、画笔、文字、高亮、马赛克、模糊和水印
- 标注颜色、粗细、透明度、笔刷样式和文字背景可调
- 图形与文字绘制后可拖动，支持撤销与重做
- 八向选区调整及与操作语义匹配的鼠标指针
- 多显示器与 Retina 原生像素输出
- 透明 PNG、圆角、阴影、剪贴板写入
- 0–60 秒延迟截图
- 可自定义全局快捷键
- 基于 Sparkle 的自分发版本检查、签名验证与自动更新

## 系统要求

- macOS 14 Sonoma 或更高版本
- Xcode，或带 macOS SDK 的 Swift 6 工具链
- 屏幕录制权限

首次截图时，请前往：

> 系统设置 → 隐私与安全性 → 屏幕录制

允许 YouShot 录制屏幕。修改权限后可能需要重新启动应用。

## 构建与运行

### Xcode

```bash
open YouShot.xcodeproj
```

选择共享的 `YouShot` Scheme，运行目标选择 `My Mac`，然后按 `⌘R`。

### 命令行

```bash
swift build -c release
```

也可以仅验证 Swift Package 构建：

```bash
swift build
swift build -c release
```

版本发布与更新托管不包含在本开源仓库中。

## 使用方法

启动后，YouShot 会常驻菜单栏，不显示 Dock 图标。

1. 从菜单栏选择截图模式，或使用全局快捷键。
2. 区域模式下，悬停窗口可吸附，单击选取窗口；拖动则进行自由框选。框选后可在选区旁选择普通截图，或从「长截图」中选择手动/自动滚动。
   长截图请框住实际滚动内容区域（例如网页正文），不要包含浏览器标签栏。
3. 如设置了延迟，选区完成后开始倒计时。
4. 普通区域截图完成后会在原位置显示标注层；点击绿色勾复制，点击下载按钮保存 PNG。
5. 长截图会在选区旁实时生成拼接预览。手动模式下在选区内缓慢滚动；自动模式会自动滚动并在页面到底时停止。两种模式均可暂停、提前完成或取消。
6. 长截图完成时已复制到剪贴板，同时会打开预览窗口供首尾裁剪和保存。

按 `Esc` 可以取消选区、倒计时或标注；文字输入过程中按 `Esc` 会优先取消输入。

## 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 当前屏幕 | `⌥⇧⌘3` |
| 区域截图 | `⌥⇧⌘4` |
| 全部屏幕 | `⌥⇧⌘5` |
| 滚动长截图 | `⌥⇧⌘6` |

快捷键可以在「设置 → 快捷键」中重新录制。

标注时，画笔、直线和箭头按住 `⇧` 可吸附为水平、垂直或 45° 直线；矩形和椭圆按住 `⇧` 可绘制正方形或正圆。

## 输出

- 当前屏幕和全部屏幕截图会直接保存为无损 PNG，并自动写入剪贴板
- 区域截图点击绿色勾只复制到剪贴板，点击下载按钮才保存文件
- 输出尺寸为 `截图点尺寸 × 显示器像素比例`
- 窗口吸附截图使用独立窗口采集，可保留透明圆角并排除系统投影
- 菜单和高层浮窗使用触发瞬间的屏幕合成帧，保留透明、模糊及其背景效果
- 可选择是否在成品中包含触发截图时的鼠标指针
- 长截图自动复制到剪贴板，并打开独立预览窗口供首尾裁剪和保存；鼠标指针不会进入长截图
- 只有自动滚动长截图需要「辅助功能」权限；手动滚动仅需原有的「屏幕录制」权限

## 项目结构

```text
Sources/YouShot/
├── YouShotApp.swift          # 菜单栏、设置窗口、热键注册
├── ContentView.swift         # 多标签设置界面
├── CaptureController.swift   # 截图、保存、编辑状态
├── RegionSelector.swift      # 区域选择与窗口吸附
├── ScrollCapture.swift       # 自动滚动、Vision 拼接、实时 HUD 与长图预览
├── AnnotationOverlay.swift   # 原位置全屏标注层
├── EditorView.swift          # 标注画布、工具栏、文字输入
├── AnnotationRenderer.swift  # 标注模型与渲染
├── ImageMosaic.swift         # 马赛克、模糊、PNG 写入
├── AppSettings.swift         # 设置持久化
├── HotKeyManager.swift       # Carbon 全局热键
├── KeyChord.swift            # 快捷键模型
└── CaptureMode.swift         # 截图模式
```
